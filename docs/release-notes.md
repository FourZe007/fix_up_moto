# Catatan Rilis (What's New)

Connect ("What's New in This Version"). Versi terbaru ada di atas. Jangan hapus
bagian versi lama: setiap rilis menambah satu bagian baru di atasnya.

Yang baru di versi 2.1.0:

• Bilah menu bawah kini berbentuk kapsul yang melayang di atas halaman.
